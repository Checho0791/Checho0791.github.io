# Calculadora 3D

PWA para calcular costos y precio de venta de impresiones 3D.

## Archivos
- `index.html` — aplicación
- `manifest.json` — configuración PWA
- `sw.js` — caché/offline
- `icon-192.png` y `icon-512.png` — iconos

## Publicación
Subir todos los archivos a la raíz del repositorio de GitHub Pages.

La instalación como aplicación funciona cuando el sitio se sirve por HTTPS (GitHub Pages lo hace automáticamente).
